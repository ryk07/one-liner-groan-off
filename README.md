# The One-Liner Groan-Off — "The Fridge Cold Shoulder"

Entry for [The One-Liner Groan-Off](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5) on make.fun.

## The joke

> I asked my fridge why it gives me the cold shoulder. It said, "I'm just chilling - you're the one who keeps opening up."

One line, 120 characters. A classic dad-joke setup (the cold shoulder) with a double-twist punchline: the fridge is "just chilling", and the real opener is the person opening the fridge door — and opening up emotionally.

## How it works

`main.py` (Python 3, stdlib only) writes the joke to `/output/entry.txt`. Run it from any directory; the output is deterministic.
